# Physics Sketch

Physics Sketch - Android-приложение для быстрых физических схем, конспектов и черновиков на телефоне или планшете.

Я не нашел удобной альтернативы, где можно быстро рисовать учебные схемы и одной кнопкой отправлять ZIP-набор рисунков без фона. Поэтому решил сделать минималистичную рисовалку с этой функцией: открыть чистый лист, набросать схему, поставить стрелки, добавить формулы, сохранить набор и сразу передать его дальше.

## Зачем оно нужно

Physics Sketch помогает быстро оформить мысль в понятный рисунок:

- разобрать задачу по физике на схеме;
- нарисовать силы, векторы, углы и тела;
- сделать конспект прямо во время пары;
- подготовить аккуратный рисунок для отправки преподавателю или одногруппникам;
- хранить несколько наборов рисунков по темам или лекциям.

Это не графический комбайн. Это рабочая рисовалка для учебных схем: открыл, нарисовал, поправил, сохранил.

## Что умеет версия 1

- Рисование от руки стилусом или пальцем.
- Настройка толщины пера и размера ластика.
- Ластик для объектов и рукописных штрихов.
- Отмена и повтор действий.
- Фигуры: стрелка, круг, прямоугольник, горизонтальная линия, вертикальная линия, наклонная линия.
- Удобное изменение размера линий и стрелок за концы.
- Поворот объектов через отдельный режим вращения.
- Текст и математические символы с физическими пресетами.
- Отметка угла между двумя прямыми.
- Выбор объекта тапом.
- Быстрое меню по долгому нажатию: удалить, дублировать, вращать.
- Подтверждение перед удалением.
- Импорт PNG и PDF как основы для рисунка.
- Выбор страницы при импорте многостраничного PDF.
- Масштабирование импортированных страниц.
- Экспорт набора рисунков в ZIP.
- Импорт сохраненного ZIP обратно в приложение.
- Создание, переименование и удаление наборов и отдельных рисунков.
- Работа на телефоне и Android-планшете.

## Для кого

- Студенты физики, математики и инженерных направлений.
- Преподаватели, которым нужно быстро показать схему.
- Любой, кто объясняет задачу через рисунок, а не через длинный текст.

## Как устроено

Проект разделен на понятные части:

- `core/model` - объекты рисунка, история, документы и наборы;
- `core/geometry` - точки, границы, повороты и проверки попадания;
- `core/render` - отрисовка, PNG/PDF/ZIP;
- `core/tools` - инструменты и палитра символов;
- `data` - локальное хранение и переносимые архивы;
- `ui` - экран редактора, холст и панели управления.

Формат данных сделан переносимым: рисунки хранятся в JSON, а наборы можно экспортировать в ZIP. Это пригодится для будущих версий под iOS и Windows.

## Технологии

- Android
- Jetpack Compose

- JSON storage
- PNG/PDF/ZIP import and export

## Статус

Версия 1 готова для Android-тестирования и первого релиза. Приложение уже проверено на телефоне и Android-планшете.

Следующие крупные этапы - нативная iOS-версия на Swift/SwiftUI и версия для Windows. Цель та же: быстрые схемы, понятный интерфейс и удобный обмен наборами рисунков без фона.
